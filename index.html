Simple workflow

Set it once.
Ship the whole set.

Manual icon-sheet production becomes a guided four-step process.

  1. 01

    Choose your source

    Select a folder of AI, EPS, SVG, PNG or JPG assets and choose the destination.

  2. 02

    Configure the layout

    Set grid dimensions, gaps, naming, grouping, trace behavior and colors.

  3. 03

    Apply your template

    Optionally select an AI template, edit detected text and assign a hero icon.

  4. 04

    Run and export

    The extension builds, processes and saves each deliverable while showing progress.
